### 📊 Запрос 1: Динамика трафика и среднего чека (Самый важный!)

**Цель:** Подтвердить, что количество чеков не упало, а упала сумма в чеке.
**Сравнить:** Декабрь 2025 (база) с Январем, Февралем и Мартом 2026.

_SQL-логика:_

```sql
SELECT
    EXTRACT(MONTH FROM TO_DATE(date, 'DD.MM.YYYY')) as month,
    COUNT(transaction_id) as total_checks, -- Это наш "трафик"
    ROUND(AVG(total_amount), 2) as avg_check, -- Средний чек
    ROUND(SUM(total_amount), 2) as total_revenue -- Общая выручка
FROM transactions
WHERE date >= '01.12.2025' AND date <= '31.03.2026'
GROUP BY month
ORDER BY month;
```

_(Если делаете в Excel: постройте сводную таблицу, где в строках – Месяц (из колонки date), а в значениях – Количество по `transaction_id` и Среднее по `total_amount`)_.

### 📊 Запрос 2: Изменение структуры заказов (Что именно перестали покупать?)

**Цель:** Понять, какие категории блюд "просели".
**Сравнить:** Топ-5 самых частых `item_name` в Декабре 2025 vs Топ-5 в Январе-Марте 2026.

_SQL-логика:_

```sql
SELECT
    item_name,
    COUNT(transaction_id) as times_ordered,
    SUM(quantity * price_per_unit) as item_revenue
FROM transaction_items
JOIN transactions ON transaction_items.transaction_id = transactions.transaction_id
WHERE date >= '01.12.2025' AND date <= '31.03.2026'
GROUP BY item_name
ORDER BY times_ordered DESC
LIMIT 10;
```

_(В Excel: сводная таблица, в строках – `item_name`, в значениях – Количество по `transaction_id`. Добавьте фильтр по дате и посмотрите топ за декабрь и топ за 1-й квартал)._

### 📊 Запрос 3: Текучесть ключевого персонала

_SQL-логика:_

```sql
SELECT
    restaurant_id,
    position,
    COUNT(CASE WHEN termination_date >= '01.12.2025' AND termination_date <= '31.03.2026' THEN 1 END) as fired_count,

GROUP BY restaurant_id, position;
```

## 🟣 Вариант 4: Python (для продвинутых)

Если умеете работать с Python, используйте библиотеку `pandas`:

```python
import pandas as pd

# Загрузка данных
transactions = pd.read_csv('transactions.csv', sep=',')
items = pd.read_csv('transaction_items.csv', sep=',')

# Запрос 1: Динамика чеков
transactions['date'] = pd.to_datetime(transactions['date'], format='%d.%m.%Y')
result1 = transactions[transactions['date'] >= '2025-12-01'].groupby(
    transactions['date'].dt.month
).agg(
    total_checks=('transaction_id', 'count'),
    avg_check=('total_amount', 'mean')
).round(2)

print(result1)

# Запрос 2: Топ блюд
merged = items.merge(transactions, on='transaction_id')
result2 = merged.groupby('item_name').agg(
    times_ordered=('transaction_id', 'count'),
    revenue=('price_per_unit', lambda x: (x * merged.loc[x.index, 'quantity']).sum())
).sort_values('times_ordered', ascending=False).head(10)

print(result2)
```

2.  **Технически:** Проверить работоспособность терминалов (на них тоже жалуются в отзывах), так как это дополнительно тормозит отдачу заказов.
3.  **Маркетинг:** Вернуть доверие гостей через акцию "Комплимент от шефа" за долгое ожидание, чтобы сгладить негативный опыт.
